ÉCLAT — FULL SE1020 BACKEND AUDIT & FIX RELEASE
================================================

This package retains the existing Spring Boot MVC/JSP Java application and all six
OOP member modules. It is not a replacement static website.

Included:
- Public Wezoree-inspired marketplace at GET /, accessible without login.
- Customer/admin dashboards and all six module pages.
- Sri Lankan district/location filter and vendor category/name filters.
- Booking edit flow for a customer's own pending booking.
- Admin contract edit/cancel flow.
- Customer pending-review edit flow.
- Authorization and ownership checks across plan, booking, contract, payment,
  vendor and review actions.
- Booking date conflict checks at both request creation and confirmation.
- Contract/booking reference and date-range validation.
- Payment date/method/amount validation and audited payment void flow.
- UTF-8 atomic file persistence, synchronized repository writes and UUID IDs.
- Isolated test data directory for automated tests.
- Full audit report, QA matrix, final report template, viva notes and class diagram.

Run:
1. Back up the existing OOP Project/data folder if it contains your account or records.
2. Extract this ZIP to a new folder.
3. Copy your backed-up data folder into the new OOP Project folder if you need to keep
   your existing customers/bookings/contracts. The CSV format has been retained.
4. Run mvnw.cmd test.
5. Run mvnw.cmd clean package.
6. Run run-web.bat and open http://localhost:8080/.
