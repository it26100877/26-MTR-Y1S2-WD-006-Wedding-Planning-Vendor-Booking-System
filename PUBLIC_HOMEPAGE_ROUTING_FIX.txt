ÉCLAT PUBLIC HOMEPAGE ROUTING FIX
=================================

This release fixes the root URL routing.

Before:
- GET / redirected visitors to /login or /dashboard.
- The public marketplace JSP was therefore never displayed.

After:
- GET / displays the public marketplace (public-home.jsp) without login.
- Vendor categories are supplied to the public homepage.
- GET /dashboard still requires an authenticated session.
- Existing six Java modules and services are retained.

INSTALL:
1. Stop the currently running application with Ctrl+C in its Command Prompt.
2. Extract this ZIP to a NEW folder.
3. Open the OOP Project folder.
4. Run run-web.bat.
5. Open http://localhost:8080/ in a private/incognito window to test the public homepage.
6. Sign in only when testing dashboard, booking, or wedding-plan actions.

The dashboard URL remains http://localhost:8080/dashboard.
